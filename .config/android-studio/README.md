# Android Studio Customizations

This directory contains local Android Studio customizations:

- `themes/xcode-dark/` contains the Xcode-inspired UI theme and editor scheme.
- `plugins/no-completion-ads/` contains the source and built JAR for disabling completion advertisements.
- `vendor/ataman-intellij/` contains a vendored snapshot of Ataman IntelliJ.

Ataman fork: `https://github.com/JustasPolis/ataman-intellij`

The vendored Ataman snapshot was fetched on September 22, 2026 from commit
`b1c4a86016003ff59ef11b8550c411607c6f1005`.
